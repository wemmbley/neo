# Neo 🌴

Neo - профессиональный PHP-фреймворк разработки сайтов написанный полностью "с нуля".

# Задачи

Его задача - дать весь необходимый функционал разработчику для достижения 3 целей:
- `Performance` - высокая производительность и возможность отладки всей цепи 
вызовов внутренним профилировщиком. Ставка строго на оптимизацию.
- `Security` - сделать взлом сайта практически невозможным. Выдать максимальный 
инструктаж пользователю перед литьем кода на боевой сервер.
- `Stability` - стабильность, которая достигается тестированием, приближенной 
к философии TDD. Чтобы каждый новый цикл-итерация разработчики внедрения 
нового функционала гарантированно не ломал старый.

# Функционал

Отдельно функционал покаместь не описываю. Лог разработки ведётся поверсионно
