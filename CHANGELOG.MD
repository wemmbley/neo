# Neo
# v1.0.0
### Ядро
- Реализован автозагрузчик классов
- Все настройки автозагрузки вынесены в корневой файл `autoload.php`
- Полный цикл DependencyInversion: `Application` -> `ServiceContainer`
  -> `ServiceProvider` -> `Service` с автоматическим внедрением
  зависимостей через конструктор сервиса.
- Биндинг трёх видов в сервис провайдере в контейнер: `bind`, `singletone`,
  `instance`
### Модули
- Реализована система тестирования `neo/Testing`
- Реализована система языков `neo/Lang`
- Реализована система валидации `neo/Validator`
- Система консоли `php cli` с возможностью расширять её своими
  командами через класс-наследник `Command` и регистрацией его в `autoload.php`
- Реализация паттерна `DTO`, 'DataMapper', `Validator` в одном месте через
  шаблон `Transfer`
### Хелперы
- Функции дампа и дебага: `dd()`, `dump()` с рекурсивной вложенностью
- Вспомогательная функция `__()` для строчных переводов
- Вспомогательная функция `base_path()` для получения пути
  относительно корня проекта
- Функции для получения конфигов и переменных окружения: `config()`, `env()`
- Функция `app()` для мгновенного поулчения инстанса класса из контейнера

# v2.0.0
### Ядро
- Добавлены фасады. Интерфес `Facade` со статическим вызовом `::` без `use` для 
использования. Подключаются через атрибут `FacadeOf` и `extends Facade`
- Оптимизирован `ServiceProvider`: теперь он подгружается лениво, без лишних 
созданий классов
- Общее количество тестов перевалило за `1000`+
### Модули
- Добавлена система `Chronos` с фасадом `Chronos::` который точно позволяет 
работать с датой и временем
- Добавлена система хранилища `Storage` с фасадом `Storage:: `и тесты к ней. 
Полное управление файловой системой
- Добавлена система логирования `Logger` с соответствующим фасадом `Log::`
- Добавлена система кэширования `Cache` с фасадом `Cache::`
### Минор
- Добавлен базовый обработчик всех `\Exception`.
- Добавлено 3 новых параметра в `.env` - `APP_DEBUG`, `APP_DISPLAY_ERRORS`,
`APP_PROFILER` для включения режим разработчика, режима показа отладки и 
профилировки приложения.
- Усовершенствован `Bootstrap.php`, он теперь стал лаконичнее и понятнее
- FIX: `ServiceProvider` не загружались; инстанс не создавался
- Добавлен удобный синтаксис биндинга зависимостей прямо в провайдере 
через `$this->app->bind()`
- В модуль `Testing` функция `skip()` была расширена условием вызова и 
причиной пропуска теста.
