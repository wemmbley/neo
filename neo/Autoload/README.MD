# Автозагрузчик

Это семантическое пространство необходимо для автоматической 
подгрузки всех классов приложения. Это прямая замена ненужного 
Composer в пользу собственной разработки.

# Настройка

- `classes` список конкретных классов для загрузки
- `files` список конкретных файлов для загрузки

```php 
$autoload = new Autoload($classes, $files);
$autoload->load();
```
