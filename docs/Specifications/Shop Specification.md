# Спецификация модуля Интернет-Магазина.

# Архитектура БД.

Мастер-товары в `products`, вариации в `product_variants`. 
Еденичный товар всегда имеет мастер-продукт и 1 вариацию.
SEO привязывается к мастер-товару, permalink - тоже. 

### Схема БД:

| Имя таблицы                  | Предназначение                                  |
|------------------------------|-------------------------------------------------|
| products                     | Базовые мастер-продукты                         |
| product_variants             | Мультивариативность конкретного мастер-продукта |
| variant_attribute_values     | Many-to-Many связь атрибутов с их значениями    |
| product_translations         | Переводы мастер-продукта                        |
| attributes                   | Список атрибутов товара: `цвет`, `размер`       |
| attribute_translations       | Переводы имён атрибутов                         |
| attribute_values             | Список значений товара: `красный`, `L`          |
| attribute_value_translations | Переводы значений товара                        |
