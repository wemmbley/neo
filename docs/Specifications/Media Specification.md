# Медиа

Пользователь в теории может загружать файлы, админ - гарантированно. 
Мы должны сделать универсальный способ скрепления файлов к моделям.

### Схема БД:

| Имя таблицы        | Предназначение                     | Структура                                                                          |
|--------------------|------------------------------------|------------------------------------------------------------------------------------|
| media              | Например, картинка                 | site_id, disk, path, mime, size, width, height, hash, conversions JSON, created_at |
| mediables          | Синхронизация                      | media_id, mediable_type, mediable_id, collection                                   |
| media_translations | Переводы alt и описания медифайлов |                                                                                    |
