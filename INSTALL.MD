# Установка

## Шаг 1. Env

Для начала скопируйте `.env.example` в `.env`. 

Далее настройте его под свои нужды. Особое внимание уделите блоку баз данных. 
Если Вы используете MySQL то хост ставьте `127.0.0.1` вместо `localhost`. 

### Пример конфигурации MySQL: 
```dotenv
DB_CONNECTION=mysql
DB_DATABASE=neo
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USERNAME=neo
DB_PASSWORD=LRKH2335G4tSPEBY
```

### Пример конфигурации SQLite:
```dotenv 
DB_CONNECTION=sqlite
DB_DATABASE=app/Database/Database.sqlite
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=
```

## Шаг 2. Генерация ключа

Наше приложение основано на криптографии, для организации которой 
необходима соль. Она позволяет уникализировать каждый хэш, который 
Вы будете делать относительно Вашего конкретного приложения. 

Выполните в консоли:
```bash
php cli key:generate
```

## Шаг 3. Симлинки (только в UNIX!)

Если Вы используете UNIX-подобную систему по типу Linux, обязательно
выполните линковку файлов, она пригодится для файловой системы.

Выполните в консоли:
```bash
php cli storage:link
```

## Шаг 4. Миграции

Мы используем свои системные таблицы в БД которые нужны для 
полноценной рабты приложения, поэтому миграции для старта 
являются обязательным шагом. 

Выполните в консоли:
```bash
php cli migrate
```

## Шаг 5. Финал.

Перед стартом нужно понять, все ли модули и функции включены в PHP,
правильно ли настроены права и роли на UNIX-системах, и многое другое.

Выполните в консоли:
```bash
php cli validate
```

Если нет ошибок - все хорошо, приложение запущено успешно!
